# Scripts da edição final — Vícios da Mente: Inveja

[Baixar os scripts e configurações finais (ZIP, 10,3 MB)](https://media.githubusercontent.com/media/raphaelfigueredo2024/v-deo/main/VICIOS-DA-MENTE-INVEJA-SCRIPTS-FINAL.zip)

Inclui 28 arquivos Python: os 27 scripts preservados de produção/planejamento/validação e o patch histórico da revisão. Também contém linha do tempo, planos das 154 cenas, 820 legendas, ASS final, frase de abertura pronta, imagens oficiais da marca, fontes, dependências, instruções e relatórios de qualidade.

O renderizador correto é `projeto/revisions/texto-v2/scripts/render.py`, dentro do ZIP. Abertura de 9 segundos, frase branca de 38 px centralizada e sem fundo; legendas amarelas de 42 px, sem fundo. Full HD, 24 fps, duração de 29min18,667s.

Este pacote contém código e configurações; as mídias grandes (154 imagens narrativas, MP3, WAVs e MP4s) são externas. O README interno descreve como executar com o projeto original e lista as dependências. Os artefatos finais PNG/ASS estão incluídos; o comando pontual que os criou não foi preservado como script separado. Os preparadores v1 e o patch são históricos e não devem ser executados para recriar os textos finais.
